# 配置DMA结构体源数据地址出现错误

错误代码

~~~c
	/* 源数据地址 */
	DMA_InitStruct.DMA_Memory0BaseAddr = *[BUFFER_SIZE];
~~~



==解释==

[BUFFER_SIZE]只是宏定义的数组长度，并非地址

Memory0BaseAdd需要内存首元素地址，所以应该填写数组名

在 C 语言的底层结构体定义中，DMA 结构体的地址成员变量类型是 uint32_t(32位无符号整数)

用(uint32_t)将此指针强制转换成一个32位无符号整数

填入地址的时候，如果想要传入数组名首地址，则需要进行强制类型转换



正确代码

~~~ c
	/* 源数据地址 */
	DMA_InitStruct.DMA_Memory0BaseAddr =(uint32_t)aSRC_Const_Buffer;
	/* 目标地址 */
	DMA_InitStruct.DMA_PeripheralBaseAddr = (uint32_t)aDST_Buffer;

~~~
