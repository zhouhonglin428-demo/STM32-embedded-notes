# STM32 嵌入式开发与实践笔记

本仓库用于系统化记录嵌入式软件开发（基于 STM32F4）过程中的核心知识点、外设驱动逻辑、避坑指南及 Debug。

## 📁 模块架构

* **01_C语言基础**：指针、内存操作、模块化开发等嵌入式 C 核心机制
* **02_STM32外设与通信**：GPIO、USART、EXTI、DMA 等底层驱动与协议实践
* **03_数据手册与开发技巧**：手册快速检索方法、工具链高效利用技巧
* **04_疑难杂症与学习心得**：架构思考、AI 辅助排查 Prompt 及阶段性推演复盘
* **05_配置与语法避坑**：常见编译错误、寄存器/固件库误区归纳
* **06_debug错误排查**：**[核心]** 实战 Bug 诊断链条（硬件时序、DMA 丢包、中断死锁等 SOP）
