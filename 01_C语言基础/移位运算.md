```
<<			左移运算
>>			有符号右移
>>>			无符号右移
```



```
<<  左移运算 如26 << 1

将26转换为二进制数一个字节，不够8位前面自动补齐0则表示为00011010
此时1.00011010整体向左移一位(变成2.),前面第一位舍弃最后一位为0变成(3.)

1.   00011010
2.  000110100 转换成十进制为52
3.   00110100 
      如果是26 << 2
1.   00011010
2. 0001101000
3.   01101000
```

```
>> 右移运算
如果正数右移，左侧补0
如果负数右移，左侧补1

如26 >> 1
1.			00011010
2.			000011010		
3.			00001101


```
